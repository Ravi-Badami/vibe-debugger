# Extension Icon

This directory should contain the extension icon file: `icon.webp`

## Icon Requirements:

- **File**: `icon.webp`
- **Size**: 128x128 pixels (recommended)
- **Format**: WebP with transparent background
- **Style**: Should represent debugging/AI assistance theme

## Suggested Design:

- Bug/debugging icon combined with AI/chat elements
- Color scheme: Blue (#007ACC) for debugging, purple (#C586C0) for AI
- Clean, modern design suitable for VS Code marketplace

## Marketplace Requirements:

- Square aspect ratio
- High contrast for visibility at small sizes
- Should be recognizable at 32x32 pixels

**Note**: WebP format is used for better compression while maintaining quality.
