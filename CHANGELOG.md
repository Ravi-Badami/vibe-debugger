# Change Log

All notable changes to the "vibe-debugger" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.1.0] - 2026-02-08

### Added

- **AI-Powered Debugging Assistant**: Interactive chat interface using `@vibedebugger` for AI-assisted debugging
- **Automatic Error Detection**: Real-time monitoring of code errors with configurable intervals
- **Smart Question Generation**: Context-aware clarifying questions before providing solutions
- **Demo Mode**: Interactive demo with sample error files (null reference, async errors, DOM errors)
- **Configurable Notifications**: Customizable error notifications with rate limiting
- **Context Capture**: Intelligent gathering of file content, recent changes, and error context
- **Prompt Enhancement**: AI prompt optimization for better debugging suggestions
- **TypeScript/JavaScript Support**: Full support for modern JavaScript and TypeScript debugging
- **VS Code Integration**: Seamless integration with VS Code's chat participants and diagnostics

### Features

- **Beginner-Friendly**: Designed specifically for developers learning to debug code
- **Educational Approach**: Teaches debugging by asking questions rather than just providing answers
- **Real-time Monitoring**: Automatic error detection without manual intervention
- **Interactive Learning**: Demo mode with guided examples and explanations
- **Customizable Experience**: Extensive configuration options for different user preferences

### Technical

- **TypeScript Implementation**: Fully typed codebase with strict TypeScript checking
- **Webpack Bundling**: Optimized build process with proper source maps
- **Comprehensive Testing**: Full test suite covering all components and integration points
- **ESLint Integration**: Code quality enforcement with modern linting rules
- **VS Code Extension API**: Built using latest VS Code extension APIs
